# Craving: export-report

- Stage: Craving
- Owner: PM
- Size limit: 40 lines
- Source: none (start of the chain)

## Problem

Users read their report on screen but cannot take the data to a spreadsheet.

## Who

Analysts who build weekly summaries by hand.

## Expected result

An analyst gets the report as a CSV file with one command and opens it in a spreadsheet unchanged.

## Out of scope

Other formats (PDF, XLSX) and scheduled exports.
