# Techniques

| Technique | Use it for |
|---|---|
| Partitions | inputs with classes that behave the same |
| Boundaries | limits: 0, 1, max, max+1 |
| State transitions | flows, including forbidden transitions |
| Decision table | combinations of conditions with different results |
| Pairwise | many options, few runs |

Every case traces to an acceptance item or a named risk; order by risk.
