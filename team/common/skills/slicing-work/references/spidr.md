# Where to cut (SPIDR)

| Cut | Example |
|---|---|
| Spike | find out first, in a time box |
| Paths | the happy path first, each error path next |
| Interfaces | one command or flag at a time |
| Data | one format or source at a time |
| Rules | the simple rule first, the exceptions next |

Each slice is vertical (through every layer) and verifiable alone.
