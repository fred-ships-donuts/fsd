# Definition of Done: an issue

1. Title `<type>: <what>`; labels `area:` and `size:`; the milestone of the phase.
2. **S**: `## What` and `## Acceptance`. **M** and **L**: What, Why (with the SPEC §), Acceptance and References.
3. Each acceptance item is one numbered line, runnable cold: command or keys → exact output and exit code (`writing-acceptance-criteria`).
4. No probable duplicate open (`fsd-issue new` checks; `--force` only when it is not one).
