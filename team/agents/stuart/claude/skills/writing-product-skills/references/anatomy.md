# Anatomy of a product skill

| Part | Rule |
|---|---|
| `SKILL.md` | the behavior; concise; links to the rest |
| `references/` | read only when needed (checklists, rules) |
| `templates/` | the shapes the skill produces |
| `scripts/` | the exact parts (consolidation, validation); never a verdict written by the model |
| `agents/` | only when a subagent is really useful, with the reason |
| `evals/evals.json` | scenarios with `expected_output`, including what it must NOT do |
| `README.md` | for humans |
