# Self-review checklist

- [ ] Every line of the handoff (**What to do**, **Files**, **Contracts**) is in the diff.
- [ ] Nothing out of scope; one issue per PR.
- [ ] Existing helpers reused, none duplicated.
- [ ] Errors, exit codes and messages exactly as the spec says.
- [ ] Edge cases of **Risks** handled and tested.
- [ ] Docs and spec changed in the same PR when behavior changed.
- [ ] Every Blocking point of the last review answered by a commit, each named in the reply.
